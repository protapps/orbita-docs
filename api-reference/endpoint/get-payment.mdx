## 🔍 Consulta de Pagamento

Retorna os detalhes completos de uma transação existente, incluindo status atual, dados do cliente, informações de pagamento e produtos.

**Headers Obrigatórios:**

```
Authorization: Bearer {API_KEY}
```

---

## 📋 Parâmetros

<ParamField path="transactionId" type="string" required>
  ID único da transação (UUID). Retornado na criação do pagamento.
</ParamField>

---

## 📤 Resposta

<ResponseField name="transactionId" type="string">
  ID único da transação
</ResponseField>

<ResponseField name="status" type="string">
  Status atual da transação: `initial`, `pending`, `approved`, `declined`, `refund`, `chargeback`, `expired`, `paid`, `cancelled`
</ResponseField>

<ResponseField name="amount" type="string">
  Valor da transação (ex: "150.00")
</ResponseField>

<ResponseField name="currency" type="string">
  Moeda da transação (sempre "BRL")
</ResponseField>

<ResponseField name="paymentMethod" type="string">
  Método de pagamento: `PIX`, `BOLETO` ou `CREDIT_CARD`
</ResponseField>

<ResponseField name="customer" type="object">
  Dados do cliente

  <ResponseField name="customer.name" type="string">
    Nome do cliente
  </ResponseField>

  <ResponseField name="customer.email" type="string">
    E-mail do cliente
  </ResponseField>

  <ResponseField name="customer.document" type="string">
    CPF/CNPJ do cliente
  </ResponseField>

  <ResponseField name="customer.phone" type="string">
    Telefone do cliente
  </ResponseField>
</ResponseField>

<ResponseField name="pix" type="object">
  Dados do PIX (presente quando `paymentMethod = PIX`, `null` caso contrário)

  <ResponseField name="pix.qrCode" type="string">
    URL da imagem do QR Code PIX
  </ResponseField>

  <ResponseField name="pix.code" type="string">
    Código PIX copia e cola
  </ResponseField>
</ResponseField>

<ResponseField name="boleto" type="object">
  Dados do boleto (presente quando `paymentMethod = BOLETO`, `null` caso contrário)

  <ResponseField name="boleto.code" type="string">
    Código de barras do boleto
  </ResponseField>

  <ResponseField name="boleto.url" type="string">
    URL do boleto para visualização/download
  </ResponseField>
</ResponseField>

<ResponseField name="products" type="array">
  Produtos associados à transação

  <ResponseField name="products[].id" type="string">
    ID do produto
  </ResponseField>

  <ResponseField name="products[].name" type="string">
    Nome do produto
  </ResponseField>

  <ResponseField name="products[].quantity" type="integer">
    Quantidade
  </ResponseField>

  <ResponseField name="products[].price" type="string">
    Preço unitário
  </ResponseField>

  <ResponseField name="products[].total" type="number">
    Valor total do item
  </ResponseField>
</ResponseField>

<ResponseField name="utm" type="object">
  Dados de rastreamento UTM

  <ResponseField name="utm.source" type="string">
    UTM Source
  </ResponseField>

  <ResponseField name="utm.medium" type="string">
    UTM Medium
  </ResponseField>

  <ResponseField name="utm.campaign" type="string">
    UTM Campaign
  </ResponseField>

  <ResponseField name="utm.term" type="string">
    UTM Term
  </ResponseField>

  <ResponseField name="utm.content" type="string">
    UTM Content
  </ResponseField>
</ResponseField>

<ResponseField name="createdAt" type="string">
  Data e hora de criação da transação (ISO 8601)
</ResponseField>

<ResponseField name="paidAt" type="string">
  Data e hora de confirmação do pagamento (ISO 8601, `null` se não pago)
</ResponseField>

<ResponseField name="refundedAt" type="string">
  Data e hora do estorno (ISO 8601, `null` se não estornado)
</ResponseField>

<ResponseField name="chargebackAt" type="string">
  Data e hora do chargeback (ISO 8601, `null` se não houve chargeback)
</ResponseField>

## 💡 Exemplo Prático

```bash
curl -X GET https://api-v2.orbitapay.com.br/pay/payments/a1b2c3d4-e5f6-7890-abcd-ef1234567890 \
  -H "Authorization: Bearer sua-api-key"
```

## ⚠️ Erros Comuns

### Transação não encontrada

```json
{
  "error": "Not Found",
  "message": "Transaction not found",
  "statusCode": 404
}
```

### API Key inválida

```json
{
  "error": "Unauthorized",
  "message": "Invalid or missing API key",
  "statusCode": 401
}
```
